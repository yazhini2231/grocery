FRESHBASKET GROCERY DELIVERY APP

Features:
- Product search and category filters
- Product stock display
- Shopping cart and quantity updates
- Checkout with phone, address, delivery date and time slot
- Orders list and order confirmation page
- Inventory stock decreases after a successful order
- Data saved in inventory.json and orders.json (created automatically)

HOW TO RUN ON WINDOWS / VS CODE
1. Extract GroceryDeliveryApp.zip.
2. Open the extracted GroceryDeliveryApp folder in VS Code.
3. Choose Terminal > New Terminal.
4. Run these commands:
   python -m pip install flask
   python app.py
5. Keep the terminal open and visit http://127.0.0.1:5000 in your browser.
6. Stop the server with Ctrl+C in the terminal.

Run locally in VS Code, not in a basic online Python compiler.
This is a demo project for learning, not a production-ready application.
